## 换机与版本

本文记录的是历史试用与复制，不作为当前启用说明；当前公开协作入口见[README](../README.md)。服务源码在仓库[woshinibabawangzhe/SharedMemoryHub](https://github.com/woshinibabawangzhe/SharedMemoryHub)；Codex控制资产在客户端自有配置仓库的`codex/shared-memory-portability`（共享记忆便携恢复存档线）。该分支尚未合并，不能假定master包含接入。

必须另行携带两类私密数据：SQLite和最新清除记录的数据包，以及35份原始文件的档案包。数据包保存中心内容版本、提案与状态；原文档案保存此次迁入基线。它们均未上传GitHub，当前备份未加密，须由用户放入认可的私密或加密介质。同一所选运行目录上的副本不提供异地灾备。

数据包制作后若又采纳、编辑或永久清除，换机前须重新备份，携带最新清除记录和已核水位。原文档案使用`archive-manifest.json`逐文件验哈希；保留相对目录，供来源追溯。恢复后的旧来源绝对路径只用于历史追溯，不能当新电脑已验证路径。部署步骤见[换机部署与数据恢复](换机部署与数据恢复-v0.1.0.md)。
