# 共建路线与验收任务

公开协作版 v0.1.0 · 2026-11-11。以下是待推进任务，不表示已实现或已有排期。贡献前先用 Issue 对齐具体范围。

| 任务 | 修改范围 | 可复核的出口 |
|---|---|---|
| 第三个客户端适配 | 明确具体宿主；同步身份认证、权限、CLI、来源、说明 | 使用合成内容完成真实宿主读取和写入；越权拒绝；身份可辨；缺会话不伪造；离线继续 |
| Codex / Antigravity 原生接入 | 各自独立最小配置，不依赖个人 Harness | 两端分别有真实会话轨迹；人工修改后取得最新修订；联合结果单独记录 |
| 轻量演示环境 | 将演示需要的依赖与真实推理依赖区分 | 无模型和 Docker 的干净环境能打开演示；不自动安装推理包；依赖仍可复现 |
| 新电脑与跨平台部署 | 现有安装器、路径、锁定依赖、生命周期 | 在声明的系统和 Python 上从干净环境安装、启动、停止；无项目外写入；报告资源与未验项 |
| 中文检索质量 | 字面候选、中文短词、排序与评测集 | 冻结查询集与独立保留集；记录召回、无答案误召回及延迟；权限和状态不泄漏 |
| 分类浏览和无障碍 | 目录、详情、键盘、窄屏和缩放 | 完成查找与纠正任务；真实200%缩放可操作；保留位置；Console无新增错误 |
| 重复与关联整理 | 去重、提醒、批量预览和撤销 | 不同条件不误合并；有独有信息的条目不丢内容；旧修订整组拒绝 |
| 清除和恢复可靠性 | 墓碑、失败补偿、旧备份恢复 | 故障结果不报成功；清除内容不复活；独立记忆不被连带删除 |

## 一个贡献怎样交付

在 Issue 中写清场景、当前行为、目标行为和范围；PR 给出修改、实际测试、设备/版本以及未验项。一次提交解决一个可复核问题，保持现有权限、修订和清除保护。不要为了接入第三客户端而复用另一个客户端的身份。

MCP 可以在存在具体客户端需求时封装共同接口；本轮路线不预设重写服务或引入新的模型服务商。真实个人资料不作为协作测试集。
